# SQL Analytics Project – IBM Cloud

## Project Overview
This project demonstrates my SQL skills using a cloud-based database hosted on IBM Cloud.
The goal was to analyze structured data and derive meaningful business insights using
advanced SQL techniques.

## Database Environment
- Platform: IBM Cloud
- Database: (Db2)
- Data Type: Structured relational data

## Objective
- Design relational tables
- Write optimized SQL queries
- Perform analytical queries to answer business questions

## Database Schema
Tables included:
- Employees
- Job_History
- Jobs
- Departments
- Locations

Schema screenshots are available in the `/screenshots` folder.

## SQL Skills Demonstrated
- SELECT query by using string patterns, ranges, or sets of values
- ORDER BY
- Grouping
- Sorting
- Having Clause
- Common Table Expressions (CTEs)
- Aggregations & Grouping
  

## Sample Business Questions Answered
- Retrieve the first names F_NAME and last names L_NAME of all employees who live in Elgin, IL
- Identify the employees who were born during the 70s
- Retrieve all employee records in department 5 where salary is between 60000 and 70000
- Retrieve a list of employees ordered by department ID


## Project Structure
- `01_schema.sql` – Table creation
- `02_queries.sql` – Queries

## Notes
- Dataset is synthetic / anonymized
- No credentials or sensitive data are included
